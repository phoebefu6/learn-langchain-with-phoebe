# learn langchain with phoebe

A two-track interactive course on LangChain 1.x + LangGraph, by Phoebe Fu.

**Live site:** https://phoebefu6.github.io/learn-langchain-with-phoebe/

## Two tracks

- **Leader track (a1-a6)** - for C-level, managers, and curious minds. No code, ever. Thinking mode: what agents are, how they fail, how to govern them, and how to make build-buy-fund decisions. Every session ends with questions to ask your data team.
- **Builder track (b1-b10)** - for practitioners (DA, DE, DS, engineers). One running project, **DataDesk**, grows from a 40-line scratch agent into a multi-agent system with persistence, approval gates, RAG, and an eval suite. Dual LLM path throughout: Claude API or free local Ollama, one-line swap.

## What is here

- `index.html` - landing page with both tracks, paths, and the clickable knowledge map
- `courses/a1-a6, b1-b10` - 16 self-contained session pages (45 min each: concepts as Live/Self-study cards, build-along demos, homework, quiz, cheat sheet)
- `materials/official-course-map.md` - source research, per-session coverage tables, honest not-covered list, pre-delivery re-verify checklist
- `materials/presenter-notes-*.md` - run-of-show, preflight, never-cut beats per session

## Sources

Taught from the official docs (docs.langchain.com), the free LangChain Academy curricula, the Hermes 4-era 2026 ecosystem, and primary sources for the leader track (Anthropic engineering, McKinsey, Gartner, MIT, published case studies). LangChain moves fast - re-verify the changelog before delivering any session. Certificates stay with LangChain Academy (free).
